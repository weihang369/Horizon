# Horizon docs: a map

Horizon was built in stages, each with a written design before any code: requirements, then the UI on a mock client,
then the backend, then the AI. These docs are that record. You don't need them to run the app (see the
[README](../README.md)); read them to understand why something works the way it does.

## Where things are

| Folder | What it holds | Start with |
|---|---|---|
| [`requirements/`](requirements/README.md) | The product: vision, user stories, screens, the data contract, non-functional requirements and the decision log | [02 Functional requirements](requirements/02-functional-requirements.md), [09 Decision log](requirements/09-decision-log.md) |
| [`ui-ux/`](ui-ux/README.md) | The UI/UX stage's design papers (experience, architecture, visual and motion) | its README |

| [`ai/checks/`](ai/checks/) | What each AI milestone measured: accuracy, latency, cost, with the raw rows (`*.jsonl`) beside each report | [m15.md](ai/checks/m15.md) (the last milestone, with the latency run) |

## Reading the codes

The docs and code comments cite their reasons by code, so a line can be traced back to the decision behind it.

| Code | Means | Where |
|---|---|---|
| `D-118` | A product decision | [requirements/09-decision-log.md](requirements/09-decision-log.md) |
| `CHAT-02`, `PRF-08`, `SET-06` … | A user story and its acceptance criteria (`AC1`, `AC2` …) | [requirements/02-functional-requirements.md](requirements/02-functional-requirements.md) |
| `NFR-35` | A non-functional requirement (speed, cost, privacy) | [requirements/07-nfr-risk-cost.md](requirements/07-nfr-risk-cost.md) |
| `OQ-AI-01` | An open question handed to a later stage | [requirements/08-open-questions-handoff.md](requirements/08-open-questions-handoff.md) |
| `A1` `B4` `C1` `P2` `X9` `E1` `G2` `V10` `M3` `K5` `S7` `I1` `W4` | A decision in an AI design doc, by its letter: A = 01 agent architecture, B = 02 evaluation, C = 03 LLM parameters, P = 04 persona prompt, X = 05 context, E = 06 emotion, G = 07 turn-taking, V = 08 debate, M = 09 memory, K = 10 RAG, S = 11 safety, I = 12 images and music, W = 13 wrap-up | [ai/](ai/) |
| `M1` … `M15` | A milestone: M1–M6 the backend, M7–M15 the AI stage | below |
| `memory D13`, `rag D22` … | Decision 13 in that milestone's OpenSpec design | [openspec/changes/archive/](../openspec/changes/archive/) |
| `U-62` | A finding from the maintainer's own review during testing (the log itself isn't published) | |
| `R5`, `UXA D1`, `VMD §2.2` | UI-stage references: R = the UI build rules, UXA / EE / VMD = the UI/UX papers | [ui-ux/](ui-ux/README.md) |

Some docs mention `private/`: a git-ignored folder with launch notes and the maintainer's working files. Nothing in the
app or its tests needs it.

## Milestones

| Milestone | OpenSpec change | What it built |
|---|---|---|
| M1 | `contract-rev-1-3`, `backend-foundation` | Contract rev 1.3; FastAPI + SQLite, seed import, worlds and characters |
| M2 | `gateway-ledger-energy` | The one OpenRouter gateway, the cost ledger, budget caps and energy |
| M3 | `session-runtime` | Live sessions as event streams (1:1, group, debate, watch) |
| M4 | `generation-jobs` (+ `creation-followups`) | Background jobs for portraits, faces and songs |
| M5 | `knowledge-memory-storage` | Document upload, passages, vector and keyword search, memory storage |
| M6 | `http-client-parity` | The same app on the real backend; one test suite for both clients; CI |
| M7 | `ai-foundation` | Jev decisions, the question bank, the evaluation harness |
| M8 | `persona-context` | The persona prompt and conversation context |
| M9 | `turn-plan-emotion` | The turn plan, faces, listener reactions |
| M10 | `group-watch` | Who speaks in group chat and Watch mode |
| M11 | `debate` | The debate host, rounds and the verdict |
| M12 | `rag` | Search over a character's documents, with citations |
| M13 | `memory` | Characters remember across sessions |
| M14 | `safety` | Content rules and care for a user at risk |
| M15 | `images-music` | Portrait, expression and theme-song generation |
| | `jev-comparison` | Jev 1.13 against 1.14 on Horizon's own requests (1.13 kept) |
