### 10.1 The debate histories (`debate-history`, `naive`)

Run `20261014T100033-debate-history-de436c` ($0.05571 against $0.12760): the 13 scripts, every debate complete (154
arguments). The review is `evals/reviews/m11-histories.md`; its findings:

- **A runtime bug lost text from 45 of the 154 arguments (29 %),** confirmed against each argument's stored response
  and its token events: a first word, a last phrase, or a piece mid-reply. The coalescer's trailing timer took its
  buffered delta, waited for the session's write lock, and a settle cancelled it; a debate turn shares that lock with
  reactions, the plan and host lines. **Fixed** in `sessions/turn.py` (a timer already writing is waited for, never
  cancelled), with `test_a_token_the_timer_is_writing_is_never_lost`, which loses both pieces on the old code. Each
  damaged argument was rebuilt from its own stored response through the tag parser; nothing was re-paid.
- **`naive` writes its notes into 14 arguments** (`<e:thinking>` … `</e:thinking>`, then the argument), and 10 more
  end with a stray closing tag; the parser strips only `<e:…>`. The notes and tags were cut from the histories and
  each cut listed. `agent` never writes these tags. The `naive` fix is a choice for the user (below).
- **3 of 13 `naive` verdicts fell back to the quoted summary** (rationale over 60 words twice, a key disagreement over
  30 words, a panel id guessed as `chr_seedSofia`); 7 of 13 needed the paid retry.
