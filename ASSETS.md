# Assets

Where every asset Horizon ships comes from, and under which licence. Settings → About links here.

**Today every portrait, theme and track is a labelled placeholder** (D-52): procedural SVG portraits marked PLACEHOLDER, and theme songs and system tracks played by a WebAudio synthesiser and marked SKETCH. They're made by Horizon itself and covered by the repository's [MIT licence](LICENSE), except the system tracks, which `seed/system-tracks.json` releases as CC0. The real seed portraits and themes from the asset sprint (docs/requirements/06 §7) will replace them, and their rows will change to `ai` with full provenance.

## How to read the table

| Column | Meaning |
|---|---|
| Pattern | A repo-relative path glob (`**` spans folders), `npm:<package>` for a bundled font, or `track:<id>` for a system track in `seed/system-tracks.json` |
| Source | `procedural`: made by Horizon (code-generated or authored in this repo). `ai`: generated by a model. `library`: a third-party asset (e.g. a CC0 pack). `font`: a bundled typeface |
| Credit / provenance | Who made it. An `ai` row must name `model=`, `date=`, `prompt=` (a path to the prompt) and `technique=` (base, edit or sheet), separated by `;` |
| Licence | An SPDX identifier |

`npm run assets:check` (in `frontend/`, and in CI) fails if a shipped file has no row, a row matches nothing, or a row lacks a required field. Not shipped, so not listed: anything under `data/` (what you generate locally) and `docs/` (e.g. the image-model test results).

**Sound effects** have no files: they are synthesised at runtime in `frontend/src/audio/synth/` (procedural, MIT).
